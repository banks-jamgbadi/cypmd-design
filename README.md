# CYPMD Design Prototype

This repository contains a GOV.UK Prototype Kit prototype for the CYPMD service design work. It includes a set of example screens for admin dashboards, publication flows, change requests, and status pages.

## Requirements

- Node.js 18 or later
- npm

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the prototype locally:
   ```bash
   npm run dev
   ```
3. Open the local prototype in your browser at:
   ```text
   http://localhost:3000
   ```

## Useful commands

- `npm run dev` - start the prototype in development mode
- `npm run serve` - serve the prototype
- `npm run start` - start the prototype

## Project structure

- `app/views/` - HTML page templates
- `app/assets/` - CSS and JavaScript assets
- `app/routes.js` - route definitions
- `app/config.json` - prototype configuration
- `package.json` - project dependencies and scripts

## Notes

This prototype is built with the GOV.UK Prototype Kit and GOV.UK Frontend.
